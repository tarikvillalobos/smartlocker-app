# SmartLocker App

Aplicativo white-label para usuários de armários inteligentes, em Kotlin
Multiplatform e Compose Multiplatform, com interface em português brasileiro.

The app allows users to manage packages delivered to smart lockers, check package status, and access the information required to collect their deliveries.

## Features

- View received packages
- Check package details and status
- Access pickup codes
- Track pending and collected packages
- Receive delivery-related notifications

## White Label

This project is designed to support multiple brands and clients.

Branding, visual identity, content, and specific features may vary depending on the deployment.
